# .github

Arquivos de configuração e templates da Organization [`fiscal-digital`](https://github.com/fiscal-digital).

## Estrutura

| Arquivo | Função |
|---|---|
| `profile/README.md` | Landing page pública renderizada em [github.com/fiscal-digital](https://github.com/fiscal-digital) |

## Como editar

Edite o arquivo desejado, abra um PR. Após merge na `main`, o GitHub atualiza automaticamente a página da org (pode levar alguns minutos para propagar).

## Convenções

- Toda comunicação pública aqui segue os mesmos princípios do projeto: **factual, verificável, sem linguagem acusatória**.
- Mudanças em `profile/README.md` que afetam mensagem institucional precisam de aprovação de pelo menos 1 mantenedor.
